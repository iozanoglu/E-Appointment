E-Appointment

E-Appointment is a web-based Appointment Management Application designed for clinics and hospitals. Users can book, update, and track appointments, and view appointment statuses on a dashboard.
The backend is developed with C# and ASP.NET Core, and the frontend is built using Angular, TypeScript, HTML, and CSS. The project follows the MVC architecture and utilizes Entity Framework Core with MS SQL Server for data management.

Features
User registration and authentication
Role-based access (Admin, Doctor, Patient)
Create, update, and delete appointments
Track appointment status (Scheduled, Completed, Cancelled)
Dashboard to view appointments and summaries
RESTful API with Swagger integration
